Android USB Connection Guide

1

Enable Developer Options

Open Settings > About Phone on Android. Tap Build Number 7 times until you see "You are now a developer!".

2

Turn ON USB Debugging

Go to Settings > System > Developer Options and switch on USB Debugging.

3

Allow USB Debugging Prompt

Unlock phone, plug in USB cable, and select "Always allow from this computer" when prompted.

Device not showing up?

Try restarting the ADB daemon or replugging your USB cable.
